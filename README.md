# proxmox-cloud-init-template

Скрипт создаёт на узле Proxmox VE шаблон виртуальной машины из официального cloud-образа. Шаблон сразу готов к клонированию: cloud-init, virtio-scsi, последовательная консоль и QEMU Guest Agent.

Поддерживаемые образы:

| Выбор | Дистрибутив        | Пользователь по умолчанию |
|-------|--------------------|---------------------------|
| 1     | Ubuntu 24.04 LTS   | `ubuntu`                  |
| 2     | Ubuntu 22.04 LTS   | `ubuntu`                  |
| 3     | Debian 12          | `debian`                  |
| 4     | AlmaLinux 9        | `almalinux`               |

Для Debian используется образ `genericcloud`: в нём уже есть драйверы virtio для KVM.

Гостевой агент в образ не вшивается. Cloud-init ставит пакет `qemu-guest-agent` при первой загрузке клона, уже на диске virtio-scsi. Так initramfs собирается в настоящей ВМ и первая загрузка Debian не падает в панику ядра.

## Что настраивается в шаблоне

- диск SCSI (`virtio-scsi-single`), `discard`, SSD-эмуляция, отдельный iothread;
- привод cloud-init;
- загрузка с `scsi0`;
- пользователь, IP и при необходимости SSH-ключ, пароль и DNS;
- последовательная консоль (`serial0`, дисплей `serial0`);
- QEMU Guest Agent и fstrim при клонировании;
- генератор случайных чисел `/dev/urandom`, чтобы первая загрузка не ждала энтропию;
- диск облачного образа увеличивается на заданный размер (по умолчанию `+10G`). Файловая система растягивается cloud-init при первом старте клона.

Скачанный образ лежит во временном каталоге `/var/tmp` и удаляется сразу после импорта в хранилище. Если скрипт прервался после создания ВМ, незавершённая ВМ удаляется вместе с дисками. Повторный запуск убирает временные каталоги прошлых запусков, которые не успели удалиться.

## Требования

- Узел Proxmox VE и запуск от root.
- Хранилище с типом содержимого `images` (по умолчанию `local-lvm`).
- Каталоговое хранилище со `snippets` (по умолчанию `local`). Включение: Datacenter → Storage → `local` → Content → Snippets.
- Доступ узла в интернет на время загрузки образа.
- Клону нужен интернет при первой загрузке, чтобы установить `qemu-guest-agent`.

Команды `qm`, `pvesm`, `wget`, `qemu-img` и `sha256sum` уже есть на узле Proxmox.
